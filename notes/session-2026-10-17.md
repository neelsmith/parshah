# Session summary — 2026-10-17

## Done

- Created `data/parshiyot.psv`: pipe-delimited table of the 54 weekly parshiyot.
  - Columns: `id|label|hebrew|parshah|haftarah_ashkenazi|haftarah_sephardi`
  - `id`: `p01`–`p54` in Torah order; `label`: transliterated name (Hebcal spelling);
    `hebrew`: unpointed Hebrew name; `parshah`: Torah reading range.
  - Citations use Arabic numerals for book numbers (`1 Kings`), `-` for ranges,
    `; ` to separate discontinuous segments (e.g. `Isaiah 6:1-7:6; Isaiah 9:5-9:6`);
    every segment names its book explicitly.
  - Ranges always give the chapter on both ends (`Isaiah 60:1-60:22`, not
    `Isaiah 60:1-22`); single verses stay as `chapter:verse` (`Jeremiah 3:4`).
- Cross-checked all parshah ranges and haftarot against `@hebcal/leyning`
  (`getLeyningForParsha`); all rows agree.

## Web app (added later in session)

Layout:

- `src/hebrewdate.js` — Gregorian/Hebrew calendar arithmetic on fixed day numbers
  (R.D.), after Dershowitz & Reingold; gematriya + Hebrew month names for display.
- `src/sedra.js` — our own parshah scheduler. Segments the year at anchors
  (Tishrei before Sukkot; Pesach; Shavuot; Shabbat on/before 9 Av; Rosh Hashanah)
  and joins double portions in fixed priority order until each segment fits.
  Leap years: one portion per Shabbat from Bereshit to Shavuot (no fixed
  pre-Pesach / Bamidbar anchor — e.g. in RH-on-Thursday leap years Naso precedes Shavuot).
  `readingForWeek(rd, israel)` uses the Sunday–Shabbat week containing `rd`.
- `src/data.js` — PSV parsing, citation parsing, CTS URN construction.
- `src/app.js`, `src/index.html`, `src/style.css` — UI.
- `src/build.js` — `npm run build` inlines CSS, JS modules (import/export stripped)
  and both data files into `dist/index.html` (single self-contained file, ~30 KB,
  works from file:// or a web server).
- `test/*.test.js` — `npm test` (node:test). `@hebcal/core` / `@hebcal/leyning`
  are devDependencies used **only as test oracles**: every day 1900–2100 Hebrew
  date matches; every Shabbat 1900–2100 reading matches, Israel and Diaspora.
  (A one-off run over 1583–2700 also matched.)

UI: date picker (default today, `#YYYY-MM-DD` hash for links), prev/next week,
Diaspora/Israel and Ashkenazi/Sephardi toggles (remembered in localStorage),
Hebrew date (English + Hebrew), note on next Hebrew date from sunset, Shabbat
of the week, parshah + Torah + haftarah, or festival name if a festival Shabbat.

## Versioning (added later in session)

- `package.json` `version` (semver, starting at `0.1.0`) is the single source of
  the app version. `npm run build` checks it's semver-shaped and substitutes it for
  `{{VERSION}}` in `src/index.html` (a `<meta name="version">` tag and a small
  "Version x.y.z" line at the end of the footer).
- User tags manually in git (e.g. `git tag v0.1.0`). To bump without npm creating
  a commit/tag: `npm version patch --no-git-tag-version` (or edit package.json).

## Reading texts (added later in session)

- `src/extract-texts.js` (`npm run extract [path-or-url]`) reads compnov.cex
  (default: the GitHub raw URL) and writes `data/texts.cex`: every verse cited in
  `parshiyot.psv`, in the versions named in `books.psv` (Masoretic) — 7,122 verses,
  ~2 MB. Re-run whenever citations or book URNs change. (In the Cowork VM, Node's
  fetch needs `NODE_USE_ENV_PROXY=1`; not needed on a normal machine.)
- `data.js`: `parseCex`, `segmentVerses` (ranges resolved by corpus document order).
- **Verse numbering follows compnov.** compnov's Masoretic text numbers the
  Decalogue as BHS does (Exodus 20 has 26 verses, Deuteronomy 5 has 33), unlike
  Hebcal/Mechon Mamre (23 and 30). Fixed Yitro to `Exodus 18:1-20:26` — with
  20:23 the Torah had a 3-verse gap before Mishpatim. Compared all chapter verse
  counts for the 20 books with @hebcal/leyning's table: the only other difference
  is 1 Samuel 25 (44 vs 43), which no citation touches.
- New tests: every citation resolves start..end in texts.cex; the 54 parshiyot
  tile the whole Torah with no gaps/overlaps; combined rows equal their two parts.
- UI: Torah and haftarah citations are buttons; selecting one opens a panel with
  the Hebrew text (RTL, verse numbers, a paragraph per chapter), each segment's
  citation and CTS URN, and a compnov credit. Selecting again or × closes it; it
  stays open (same kind) when moving between weeks or toggling custom.
- dist/index.html is now ~2 MB because the text is embedded.
- Cantillation switch in the text panel header (on by default, remembered in
  localStorage with the other prefs). Off = `stripCantillation()` in data.js:
  removes accents U+0591–U+05AF, meteg U+05BD and paseq U+05C0; keeps letters,
  vowels, dagesh, shin/sin dots, rafe, maqaf, sof pasuq and ס/פ markers.
